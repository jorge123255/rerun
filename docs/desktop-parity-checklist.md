## How to read and update this list

- **Verified** means the stated slice has packaged QA evidence, or G0’s build and branch identifiers were checked. **Branch** means the agent’s implementation exists but has not passed the combined Mac gate.
- **Partial** identifies a specific gap in a feature that already works in part. **Missing** means the upstream capability has no usable end-to-end Mac equivalent. **Gated** means an execution, permissions or hosting decision must come first. **Decision** covers product or distribution scope. **Open** is a queued acceptance gate.
- Keep a box open until there is an exact source revision, an app entry point and a result. For persistent data, verify it after a full quit/relaunch. For scoped data, use two coworkers. For provider and tool work, record which parts used live services versus fixtures. Existing restrictions stay in force until a row explicitly changes them.
