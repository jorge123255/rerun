# What the Rerun Mac app is missing

Use this list to port the user-facing capabilities in [original Rerun](https://github.com/jorge123255/rerun/tree/a6d63a4b542674ddd002e51b39ba0df6e0807bcc) that are absent or incomplete in the installed Mac app. Each unchecked row names the missing behavior, a way to recognize it working, and the upstream code to open first. The comparison is against the installed Mac build `2978de9` on November 3, 2026. It includes single-document import, workspace chat-title search, assistant Markdown rendering, whole-reply copying, reusable draft cards and regenerating a chosen answer in an alternate chat. There are 37 remaining feature groups.

**Recommended order.** Keep file editing and model selection in their current lanes. Make the original board and coworker chat layout the next Mac UI port. Use that layout for the remaining reply actions and the first workspace-scoped tool, including its approval and recorded result.

**How to check off an item.** Check it when you can do it from the installed Mac app. For saved items, reopen them after quitting. For private data or settings, try the same action with a second coworker. The IDs also identify these features in the earlier audit.
