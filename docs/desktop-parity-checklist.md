# What the Rerun Mac app is missing

Use this list to port the user-facing capabilities in [original Rerun](https://github.com/jorge123255/rerun/tree/a6d63a4b542674ddd002e51b39ba0df6e0807bcc) that are absent or incomplete in the installed Mac app. Each unchecked row names the missing behavior, a way to recognize it working, and the upstream code to open first. The comparison is against the installed Mac build `1656c39` on November 3, 2026. It includes single-document import, workspace chat-title search, assistant Markdown rendering, whole-reply copying, reusable draft cards, reply regeneration in an alternate chat, provider citations, per-coworker Rerun and native Codex tool grants, and the original coworker panel alongside the board. There are 34 remaining feature groups.

The Mac has one installed preview at `~/Applications/Rerun Desktop Preview.app`. Use `pnpm desktop:install` from a clean build worktree to update that copy.
